> 谋段 B1 产出（web 宪法 A.8「谋·谋局定策」；`@impeccable` + `@ui-ux-pro-max` 已实载）。
> 效力：患者管理 3 页 / 门诊服务 3 页 / 收费管理 3 页 / 药房管理 5 页（共 14 页）暖纸化换脸的唯一施工图；后续每页由独立建段 agent 忠实施工，禁偏移、禁契约外发挥。
> 取材边界：全部页级语法取自 `contract-warm-paper-world.md` ⑧（页级组件）与 ⑤（EP 收编目录），动效取自 ⑦，状态色取自 ③（A-2/A-3 已批取申请值，A-1 按批复执行）；禁发明契约外语法。

## 〇、全篇总则（14 页一体遵循的共享裁决）

1. **钤印确认点边界**：`.fuy-stamp-toast`（`fuy-stamp-in` 落章，≤1200ms 收场，文案=动词结果）只挂「弹层 / 抽屉内提交成功」；页面级成功反馈一律 ElMessage 批注条（`.fuy-message` 脸，文案沿用各页既有中文）。危险 / 失败永不钤印。依据：契约 ⑧.5 钤印浮层语法锚定弹层语境，页面级使用属契约外发明。
2. **状态胶囊双轨制**：门牌页首状态位与卡头待办计数用 `.fuy-status-pill`（语义四色 amber/success/danger/info + 文字 + 可选 `.fuy-live-dot`，实时 / 进行语义才挂呼吸）；表格行内状态一律维持 el-tag + `.fuy-tag-aa` / `.fuy-tag-strike` 既有家族（⑤#12 零改动）。同一状态语义不跨轨混用。
3. **门牌页首为每页第一节**：`.fuy-page-head`（衬线标题 22px/700/0.06em + 英文小注可省 + 右挂状态位 + 「谁·何时」批注行 12px 灰墨 + 2px 墨规收底）。批注行取会话与业务真值（签认人 / 诊区 / 时刻），空值 — 占位禁伪数据；既有 h2 卡头标题全部升格，el-card `#header` 不再承载页面名。
4. **弹层与控件挂类**：el-dialog 挂 `.fuy-dialog`、el-drawer 挂 `.fuy-drawer`、一切显式 popper 挂 `fuy-snap-popper`、表单脸挂 `.fuy-form`；ElMessageBox 函数式弹窗族不可挂类，维持 EP 默认皮 + 显式中文双按钮既有口径（零回归，蓝图不要求改其视觉）。
5. **假常量清零总表**（本批次仅此三面换真端点，api 签名见契约 ⑪.8；其余词表系后端契约枚举镜像，如 PAYER_TYPE / 票据状态 / REVIEW_TASK_STATUS_OPTIONS，保留非假常量）：
   - `WARD_OPTIONS`（P14 消费）→ `listOrgs({ type: 'WARD' })`，useAsyncTask 三态；
   - 诊区假常量（P04 诊区文本输入、P05 诊区三 option 与「目标诊区」输入、P06 诊区输入）→ `listOrgs({ type: 'DEPT' })` 下拉（出网值仍为 string code，校验逻辑不变）；
   - `DISPOSITION_OPTIONS`（P06 消费）→ `listDictItems('DISPOSITION')`（typeCode 以 V705 种子登记为准）。
6. **布局目标形态**：1440 桌面唯一；每页根挂 `.fuy-page`（max-width 1600、内边距 16、纵向 gap 12）；页面纵向序=门牌页首 → 筛选 / 操作区 → 卷宗卡主工作区 → 页脚批注（可选，仅数据时点语义）。
7. **动效预算**：路由级 `.fuy-page` 过渡归基础册；页内 `.fuy-stagger` ≤5 档 + 显隐 `.fuy-content-fade` + 行级 `.fuy-flip` / `.fuy-tag-flip`；零新增 `@keyframes`、零氛围动效、只动 transform/opacity；各页「性能代价」逐项注记。
8. **空态与错误态**：全部空态走 `.fuy-empty` 脸（「暂无〈业务客体〉」语法 + 下一步指引），既有两态门控（未检索 / 查无结果）语义保留仅换脸；错误态说问题给恢复，不得伪装空态。

1. **业务判定**：挂号窗口 / 入院处建档员在患者初次到院时建立档案；一天高频动作=录入身份基础字段、建档前匹配预检（防重复档案）、提交建档跳详情。现状最大产品问题：11 字段长表单单列 880px 纵滚，预检结论 el-alert 挤在表单上方抢首屏，且「先预检防重」的因果在版式上不可见——预检是本页的核心防错机制，却只是表单顶一行提示。
2. **信息架构**：门牌页首（标题「患者建档」+ 批注行=建档渠道 · 当日时刻）→ 主工作区=建档表单卡（`.fuy-card` 内挂 `.fuy-form`，三分节「身份基础 / 证件介质 / 建档属性」既有，节间以 `.fuy-sign-divider` 分隔）→ 右辅栏=预检卡（`.fuy-card--stitch` 叙事卡：匹配预检钮 + 结论三态区）；弹层清单=ElMessageBox 未保存提醒 / 读卡器提示（函数式维持）。禁照抄点：预检从「表单上方一行」升格为右栏常驻卡。
3. **布局骨架**：grid 两栏 `minmax(0, 600px) 320px` gap 16；左表单卡、右预检卡 sticky top 16；预检结论区 min-height 200 锁 CLS；表单 label-width 140 既有。
4. **交互与动效**：页内 stagger 三档（页首 0 / 表单 1 / 预检栏 2，40ms 级联）；预检结论显影 `.fuy-content-fade` 既有；提交成功=ElMessage「建档完成」后路由跳详情（既有零回归）；预检 / 提交按钮 loading 既有。性能代价：stagger 一次 320ms 内完成，零常驻开销；sticky 无 JS 代价。
5. **数据接线**：`createPatient` / `matchCheck`（既有签名零变动）；`mediumOptions`（IdentifierType 契约词表镜像）与 channel / archive 词表（patientDisplay 单源）保留；本页无 orgs/dicts 消费面；无建议取用端点。
6. **性能要点**：无列表无轮询；表单首屏即交互无骨架；预检卡结论区 min-height 200 防三态切换塌陷。
7. **spec 重写锚点**：门牌页首（标题 / 批注行）断言新增；双栏结构锚（表单卡+预检卡并存）新增；预检三态文案（AUTO_MATCH 归一 / SUSPECT 转人工 / 未匹配新建）断言保留；EX-46 离开守卫全用例零改动；建档成功放行标记与路由断言保留；`.fuy-form` / `.fuy-card` 挂类断言新增。
