### 2.1 IoTDA 边界管理台实装设计（裁决 3 附带设计，PR-2 执行依据）

- **注册表接口双实现**：fuyun-iot 内定义进程内接口 `IotDeviceRegistry`，双实现 **HuaweiIotdaRegistry**（华为云 IoTDA 设备管理开放 API/SDK：产品上架/物模型同步/设备注册与一机一密凭证签发/命令下发/设备影子查询/网关与子设备拓扑）+ **SimulatedRegistry**（本地模拟实现：dev/test 无云依赖与 CI 离线场景）——与 M13 `InsuranceSimulatorAdapter` 模拟适应器同款先例；经配置切换、对管理台调用方透明，生产走华为云实现。
- **凭证安全**：AK/SK 经环境变量注入（根宪法红线：禁止硬编码）；设备密钥明文不入库、凭证重置热更新=FU-M14-01 既有口径（14-iot Spec §6）。
- **管理台全流程**：即 FU-M14-02「新设备类型上架流程」的实装化——建产品→定义物模型→MDC 术语映射（iot_metric_dict）→命令安全等级标注（FU-M14-09 白名单数据源）→设备注册，全程管理台操作留痕（审计切面）。
- **真栈演示链路**（DoD 第 1 条载体）：iot-simulator 生产级输液剧本（滴速衰减→余量告急→断流，指标值域/频率对齐真实临床）→ 华为云 IoTDA 实例 → AMQP 主链路 → M14 告警引擎 → 联动动作（输液告急→PDA 强提醒经 M01 通知中心）。
- **依赖版本**：IoTDA 管理 SDK 版本锁定 <执行时实取>（以 docs/language 技术栈定稿表为准；表外依赖先在 PR 描述申报后入表）。
