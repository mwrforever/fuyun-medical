# PR-4F 元素级 UI 访问控制 + 权限管理台（UI Perm）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 D-32~D-35 落元素级 UI 访问控制（40 元素码 + `v-perm`/`hasPerm` 双入口 + 无码全隐藏）与 system 域权限管理台（角色×权限矩阵读写端点 + workstation 管理页），并以 RabbitMQ 镜像 dict 广播先例承载 PermissionRegistry 运行期刷新与受影响会话踢出，收口 W-96②③与 W-97。

**Architecture:** perm_type 新增 `ELEMENT` 第三命名空间，元素码复用 D 册 UserVO.permissions 混出链路（登录链零结构改动，前端按 `:btn:`/`:panel:` 段消费）；管理面新建 `RoleAdminController`/`PermissionAdminController`（不扩 AuthController），矩阵写=全量覆写（diff 删插 + @AuditLog + 事务），事务提交后经 `SystemEventPublisher` AFTER_COMMIT 形态广播 `system.permission.changed` 至 fy.topic，各实例经匿名排他广播队列幂等重载 PermissionRegistry（403 面实时生效），治理命名队列单实例消费承担幂等三步 + 受影响角色会话键清理（踢出重登）；前端管理页挂新 MENU 码 `system:permission:manage`（ADMIN 专属），四错位 MENU 绑定随 V1121 扩绑收口。

**Tech Stack:** Java 17 / Spring Boot 3.5（MVC + MyBatis-Plus + RabbitMQ 治理构件 M20）；Flyway V1120/V1121（system 目录）；Vue 3 + Pinia + 自定义指令（workstation）。

    private Set<String> parseBindingPairs(String classpathSql) throws IOException {
        Set<String> pairs = new HashSet<>();
        Pattern pattern = Pattern.compile("\\('([A-Z_]+)', '([^']+)'\\)");
        try (BufferedReader reader = new BufferedReader(new InputStreamReader(
                requireNonNull(getClass().getResourceAsStream(classpathSql)), StandardCharsets.UTF_8))) {
